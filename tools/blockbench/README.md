# Blockbench (external)

Blockbench is **not** vendored in Tortuca. Install locally when authoring hero/prop GLBs:

```bash
git clone https://github.com/JannisX11/blockbench.git
cd blockbench && npm install && npm run dev
```

Workflow for PlayCanvas games: [`docs/BLOCKBENCH_WORKFLOW.md`](../../docs/BLOCKBENCH_WORKFLOW.md).
