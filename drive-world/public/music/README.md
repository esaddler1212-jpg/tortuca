# City Nights — your playlist

Drop **CC0 or tracks you own** here (`.mp3`, `.ogg`, `.wav`), then list them in `playlist.json`:

```json
{
  "tracks": [
    { "file": "my-night-drive.mp3", "title": "Night drive" }
  ]
}
```

In-game: **Settings → Music → Use my playlist**. Procedural radio stays available when the playlist is empty.
