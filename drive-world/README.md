# Drive World (prototype)

PlayCanvas + Ammo **raycast vehicle** on a **multi-kilometre** map — cruise and drive as fast as you want; no races or events.

```bash
npm install
npm run dev
```

Controls: **WASD** or arrow keys (throttle / steer).

Design roadmap: [`../docs/OPEN_WORLD_DRIVING.md`](../docs/OPEN_WORLD_DRIVING.md).
