# Third-party asset marketplaces (docs only)

Per `AGENTS.md`, do **not** embed marketplace SDKs or store browse UIs in the Tortuca PWA. Use this list for **manual** downloads and `CREDITS.md` lines.

| Marketplace | Best for | License note |
|-------------|----------|--------------|
| [Kenney](https://kenney.nl/assets) | City/road/nature kits | CC0 — `install-free-packs.sh` |
| [Poly Haven](https://polyhaven.com) | HDRIs, materials | CC0 |
| [AmbientCG](https://ambientcg.com) | PBR surfaces | CC0 |
| [Poly Pizza](https://poly.pizza) | Hero GLB bits | Check per asset |
| [OpenGameArt](https://opengameart.org) | Modular packs | Per-file license |
| [Sketchfab](https://sketchfab.com) | Hero landmarks | Often NC — read terms |
| [Unity Asset Store](https://assetstore.unity.com) | Reference only | Not redistributable via web |
| [Unreal Marketplace](https://www.unrealengine.com/marketplace) | Reference only | Engine-bound |

Ship path: copy into `drive-world/public/models/` or `flight-nemulator/public/models/`, gitignore large packs, document in the game’s `CREDITS.md`.
