# Iris talking orb — pick a style

Device-local: **Settings → HUD layout → Iris talking orb** (`hudPrefs.irisOrbStyle`).

| # | ID | Name | Best for |
|---|-----|------|----------|
| 1 | `ops-console` | **Ops console** | Home core: live caption, in-ring shortcuts (Inbox / Do / Pulse / Plan), optional ask budget. |
| 2 | `classic` | Classic reactor | Original cyan core; respects K.A.R.A. filament toggle when combo HUD is on. |
| 3 | `filament` | K.A.R.A. filament | Canvas filament orb always on (ignores filament checkbox). |
| 4 | `waveform-arc` | Waveform arc | Oscilloscope bars along the bottom while listening or speaking. |
| 5 | `sonar` | Sonar pulse | Extra ping rings when the mic is live or Iris is talking. |
| 6 | `cinema-eye` | **Cinema eye** *(default)* | Iron Man strip eye scaled into the home core. |
| 7 | `lantern` | Lantern gold | Gold-forward accent shell (same tap-to-talk). |
| 8 | `status-cross` | Status cross | Large N/E/S/W count badges when inbox, todos, or pulse need attention. |
| 9 | `team-roster` | Team roster | Shows the last specialist Iris delegated to. |
| 10 | `capsule` | Capsule chip | Compact pill in the voice dock; home core falls back to classic. |

**Default:** `cinema-eye` (#6). Change anytime in Settings → HUD layout.

Related: voice dock uses **Capsule** or **Ops console** mini layouts; other styles keep the cinema strip avatar.
