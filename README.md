# Digital Fidget Spinner

A satisfying, physics-based digital fidget spinner built with vanilla HTML, CSS, and JavaScript.

## Features

- **Realistic physics** — drag to spin with momentum and friction
- **Live stats** — RPM, total spins, and personal best
- **5 color themes** — switch with the Theme button
- **Particle effects** — sparkles at high speeds
- **Touch-friendly** — works on desktop and mobile

## Run locally

```bash
# Python 3
python3 -m http.server 8080

# Or Node.js
npx serve .
```

Then open http://localhost:8080

## How to use

1. Click and drag the spinner in a circular motion
2. Release for a fast flick — momentum carries it forward
3. Watch it coast down naturally with friction
4. Try to beat your best RPM!
